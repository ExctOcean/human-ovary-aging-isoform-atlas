# Human ovary aging isoform atlas

**A single-nucleus long-read transcriptomic atlas of the human ovary reveals concordant age-associated isoform usage and 3′UTR remodeling**

## Study overview

This study combines paired Illumina short-read and Oxford Nanopore long-read single-nucleus RNA sequencing of ovarian tissues from four premenopausal donors. The atlas profiles 36,403 nuclei across eight cell types and comprises 105,878 transcripts.

We identified 302 concordant age-associated isoforms (CAIs), which show differential usage in at least two cell types with consistent directions of change. Compared with isoforms differentially used in a single cell type, CAIs have longer median 3′ untranslated regions (3′UTRs) and more predicted RNA-binding-protein and microRNA recognition sites.
